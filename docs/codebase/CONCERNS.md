**Future research:** Q compensation for cascaded slope stages currently uses `q^(1/N)` per stage (resonance-comparability goal — same peak feel at the Res knob across LP12/24/36/48). An alternative, corner-comparability rule `Q_stage = Q_target / sqrt(2^(1/N) - 1)` keeps the 3 dB cutoff fixed per slope but multiplies the resonance peak at steep slopes (at Res≈6: ~87× at 24 dB, ~36,000× at 48 dB) — rejected for runaway resonance. If corner stability ever matters, explore Butterworth-style non-identical per-stage Qs (flat at low Q, resonant as Q rises). See `packages/audio-engine/src/engine/filter-resonance.ts`.
